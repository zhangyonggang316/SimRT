# Qt 新版手工验收

本手册适用于 `app/QtXCPHost.exe`，不是原 Tkinter APP。完整复制本目录后双击 `START_DEMO.cmd`。
启动只校验和加载本地 A2L，不会自动连接 Ubuntu。

## 实时机

1. 在“实时机 / 模型部署”填写 SSH 主机、用户和密码，点击“连接 SSH”。密码提交后清空；勾选“记住 SSH 凭据”后仅在成功登录时加密保存。取消勾选删除记忆，重启只恢复表单、不自动连接。
2. 先确认 Ubuntu 的 PREEMPT_RT、权限和运行环境与 1 ms 方案匹配。不要向运行中的模型目录覆盖文件。
3. 默认选择 `demo.json` 指定的 ZIP；点击文件夹图标选择 `models/x280_rt_single/x280_rt_single_local/<时间戳>.zip`。APP 在内部解压并校验配对 ELF/A2L/manifest，自动加载 A2L、通信协议和端口。点击“上传产物”，目标端哈希校验成功后再启动 ELF。校验失败的 ZIP 不会上传。
4. 重新构建在 Windows MATLAB R2024b 中按 Ctrl+B，调用本地 portable-linux-toolchain；ZIP 内保留时间戳文件夹及三个文件；校验成功后删除展开目录和最外层重复 ELF，最终只保留 ZIP。按 `TOOLCHAIN.md` 操作，再选择新 ZIP。
5. 检查右侧 CPU、内存、磁盘和模型列表。仅本 APP 可确认归属的运行进程允许停止。右键可选择模型、复制路径及删除模型。删除前先停止模型；确认框显示 ELF 所在的整个远程文件夹，确认后永久删除其中全部文件并清除该模型的开机自启配置，随后刷新列表。取消不做修改；包含其它 ELF 的共享目录、越界路径和符号链接会被拒绝。
6. 每次仅选择一个开机自启模型；勾选不会立即启动，取消不会停止当前进程。实际重启验收由目标机负责人确认后进行。
7. UI-05 已移除启动参数输入，启动和新设置的自启任务均不传附加参数。部署页不再提供刷新状态、读取日志、取消任务按钮；进程状态随目标状态自动更新。
8. 模型目录只在首次连接、修改目录、手动刷新及上传/删除后加载；资源与当前进程状态静默更新。持续点击、滚动、打开右键菜单时列表应保持稳定，后台监测中的命令应排队执行，不能无响应。外部新增/删除文件后使用刷新图标更新清单。
9. 逐项检查模型菜单的选择、启停、开机自启、复制路径、删除、刷新；运行中模型不能删除，外部进程不能停止。每项都应显示对应图标。检查信号、图表、统计/游标、标定和日志菜单的选择对象与实际操作一致。

## 诊断日志

1. 切换到“实时机 / 诊断日志”，产物校验、部署、ELF 启停和 XCP 消息统一显示在同一日志区。
2. 连接 SSH 后可点击“读取运行日志”。优先读取模型列表中选中的 ELF，否则读取部署页配置的 ELF；日志标题包含实际路径。任务执行或正在退出时不接受重复读取。
3. “复制全部”复制当前日志；“保存日志”导出相同内容；“清空显示”只清空窗口，不取消任务、不删除远程日志。日志区右键菜单也提供这些操作。
4. 无日志时复制、清空和保存按钮禁用；未连接 SSH 时读取按钮禁用。日志读取失败后应显示错误，并允许连接正常时重试。

## 观测与标定

1. 在“观测”点击“加载模型”选择 ZIP 或 A2L，协议、端口自动识别。文件未声明目标地址时使用实时机页面的 SSH 主机。文件缺少协议/端口、声明多个协议而未提供 ZIP、或 ZIP/A2L 不一致时禁止上线；默认模型为 UDP 17725。
2. 点击“上线”，在模型层级树勾选需要采集的信号，保持 DAQ 模式并开始。可整组勾选或按路径搜索；观测和标定层级对应 A2L 导出的模型/子系统，未知层级的旧文件保持原有分组。默认模型的 DAQ 周期显示 `0.001 s`，该字段只读。点击“下线”恢复本次标定并断开 XCP。
3. “统计”检查原始样本数和极值；曲线支持缩放、平移、关闭/单/双游标、子图、颜色和显示/隐藏。游标仅测量已勾选且已绘制的可见曲线；取消勾选隐藏曲线但保留缓存。单游标显示一个时刻的值，双游标另显示第二个值、时间差及值差。`*` 表示插值，超出已有数据范围显示 `--`。
4. 每信号默认保留最近 1,000,000 个原始点。1 ms 采样约对应 1,000 秒；容量内不淘汰样本，满后只淘汰最旧点。曲线和点显示均按可见范围抽样，缩放和游标读取原始数据；CSV 在后台导出完整缓存。
5. “标定”双击参数填写新原始值，确认后写入并回读验证。DAQ 期间仍可标定，不通过停止模型改变算法周期。
6. 使用“恢复本次会话”恢复原值；停止 DAQ 后可导出 CSV、PNG 或将数据发送到 MATLAB SDI。MATLAB SDI 需要另行安装 MATLAB，本次不自动化修改 MATLAB 会话。

## 停止与异常

- “观测 / 停止”只停止采集，不停止远端模型。
- 停止远端模型前，APP 先恢复标定并断开 XCP。恢复失败时不执行模型停止，应检查连接并重试。
- 关闭 APP 会尝试恢复标定与断开连接，但不会自动停止远端 ELF。恢复失败时窗口保持打开，不能当作成功关闭。
- 启停未确认、网络断连、超时或校验失败时查看统一的“诊断日志”，不重复盲目点击。

本包 Qt 自动化结果见 `validation/qt_ui`，唯一 1 ms 模型的构建及真机结果见 `validation/model_baseline`。回环测试和测试夹具截图不能替代实际 model_step 计时证据。
