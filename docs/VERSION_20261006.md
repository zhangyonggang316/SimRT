## 学习与恢复

学习入口为 [工程手册](README.md)、[技术路线](ARCHITECTURE.md)、[工具链](TOOLCHAIN.md)和 [1 ms 方案](1ms_solution.md)。各模块的注释、README 与原始测试记录继续保留。

恢复时先按同目录 `.sha256` 核对 ZIP，再解压到新的空目录。在解压后的根目录执行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ./tests/maintenance/verify_archive.ps1 -ManifestPath ./snapshot_manifest.json
```

校验通过只表示文件与清单一致。MATLAB 安装、许可证、用户 `startup.m`、操作系统以及实时机磁盘不在工程快照内；新机器仍按 [部署指南](NEW_MACHINE_DEPLOYMENT.md)重建环境和注册 SimRT 库。
